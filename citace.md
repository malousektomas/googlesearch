# Citace a zdroje

## Použité zdroje

- [Google Search](https://www.google.com/) – inspirace pro rozložení vyhledávací stránky a názvy parametrů formuláře.
- [MDN Web Docs: HTML forms](https://developer.mozilla.org/en-US/docs/Learn/Forms) – přehled formulářových prvků a jejich atributů.
- [W3C Markup Validation Service](https://validator.w3.org/) – ověření HTML.
- [W3C CSS Validation Service](https://jigsaw.w3.org/css-validator/) – ověření CSS.

## Použité prompty

- „Vytvoř stránku napodobující Google Search s vyhledávacím formulářem.“
- „Přidej stránku s co největším množstvím různých formulářových prvků.“
- „Přidej na všechny stránky odkazy na validaci HTML a CSS a na soubor s citacemi.“
